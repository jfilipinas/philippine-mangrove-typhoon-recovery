# Data inventory

Uploaded derived research tables: `analysis_table_primary.csv`, `primary_predictions.csv`, `landscape_split_assignments.csv`, `gedi_mangrove_reference.csv`, `canopy_calibration_predictions.csv`, `rai_2021_track.csv`, landscape inventory and model-status summaries. These are drawn from the original research archive.

**Not yet uploaded:** the full 56.6 MB `cell_observations.csv`, large observation cutouts, some original acquisition manifests and additional raw GEDI query tables. Their redistribution conditions and reproducibility need verification before release.

These derived tables do not by themselves constitute an independently validated complete data deposit. Source-data licensing remains with the original providers.
